# antonxue.github.io

Personal site, built with Jekyll and served by GitHub Pages from `master`.

- `_pages/home.html`: landing page
- `_pages/research.md`: full publication list
- `_pages/fun.md`: the Fun page
- `_layouts/` and `assets/css/site.css`: shared layout and styles
- `files/`: CV and paper PDFs

Preview locally with `bundle exec jekyll serve`, then open http://localhost:4000.
